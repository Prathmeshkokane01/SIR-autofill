# Fonts folder

Devanagari (Marathi/Hindi) support असलेला TTF font इथे ठेवा, जेणेकरून
`pages/api/generate-pdf.js` मराठी मजकूर असलेली PDF व्यवस्थित generate करू शकेल.

## कसं मिळवायचं
1. https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari इथे जा
2. "Download family" दाबा (zip मिळेल)
3. त्यातून `NotoSansDevanagari-Regular.ttf` आणि `NotoSansDevanagari-Bold.ttf`
   ही दोन फाईल्स काढून थेट या (`fonts/`) folder मध्ये ठेवा — म्हणजे शेवटी:
   - fonts/NotoSansDevanagari-Regular.ttf
   - fonts/NotoSansDevanagari-Bold.ttf

फाईलची नावं वरीलप्रमाणेच exact ठेवा — कोड याच नावांनी फाईल शोधतो.
